Q1-1. 리스는 시퀀스에 속하는가?
A1-1. 리스트는 시퀀스에 속한다.

Q1-2. 시퀀스의 특징에는 어떤 것들이 있는가?
A1-2. 시퀀스는 요소(index)를 가지고 요소 간에는 순서가 존재한다.

Q2-1. 리스트와 튜플의 다른 점은 무엇인가?
A2-1. 리스트는 대괄호를 사용하고 튜플은 소괄호를 사용한다. 또 리스트는 값을 수정 가능하지만 튜플은 수정이 불가능하다.

Q2-2. 리스트를 튜플로 바꾸려면 어떤함수를 사용하는가?
A2-2. tuple() 함수를 사용한다.

Q2-3. 패킹과 언패킹을 설명해보자.
A2-3. 패킹은 여러값을 하나의 변수에 묶는 것 이고 언패킹은 묶여있는 값을 각각의 변수로 나누는 것 이다.

Q2-4. enumerate()함수가 하는 역할은 무엇인가?
A2-4. 리스트나 튜플 등의 요소를 반복할 때 인덱스와 값을 함께 반환하는 함수이다.

Q3-1. 리스트와 세트의 차이점은 무엇인가?
A3-1. 리스트는 순서가 있지만 세트는 없다. 또 리스트는 중복 저장과 인덱스 사용이 가능하지만 세트는 불가능하다.

Q3-2. 세트에 저장된 항목에 접근할 때 인덱스를 사용할 수 있는가?
A3-2. 세트는 순서가 없는 자료형이므로 인덱스가 존재하지 않아 사용할 수 없다. 

Q3-3. 세트 A와 세트 B의 교집합을 계산하는 수식을 만들어보자.
A3-3. (A&B)

Q3-4. 세트에 항목을 추가하는 함수는?
A3-4. add(), update()
